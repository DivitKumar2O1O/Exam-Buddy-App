EXAM BUDDY NOTES — how to put it online (free, about 2 minutes)

Exam Buddy turns long answers into short, easy notes, reads them aloud and
makes practice questions. No AI, no account, nothing to pay.

OPTION A: GitHub Pages
1. Create a new public repository on github.com (for example exam-buddy).
2. Click "Add file" > "Upload files". Drag ALL the files from this folder
   (index.html, sw.js, manifest.webmanifest and the 5 .png icons) and click
   "Commit changes". There are no sub-folders, so everything uploads in one go.
3. Settings > Pages > Source: "Deploy from a branch", Branch: main,
   folder: / (root) > Save.
4. After about a minute the link appears:
   https://<your-username>.github.io/exam-buddy/

OPTION B: Netlify Drop (easiest, no coding)
1. Unzip this folder.
2. Open https://app.netlify.com/drop in a browser.
3. Drag the whole "exam-buddy-app" folder onto the page.
4. You get a link like https://something.netlify.app. Sign up for free (or log in)
   so the site stays online, then change the name under Site settings,
   for example https://exam-buddy.netlify.app

INSTALL AS AN APP
- Android (Chrome): open the link > tap "Install app" on the page, or menu ⋮ > Add to Home screen / Install app.
- iPhone/iPad (Safari): open the link > Share > Add to Home Screen.
- Computer (Chrome/Edge): click the install icon in the address bar.
It then opens full-screen with its own icon. Notes, read aloud, flash cards and
practice questions work offline after the first visit. Reading photos and PDFs
needs internet the first time each language is used.

HOW TO USE
1. Upload a photo or PDF of the notes (or paste text). Check and fix the text.
2. Tap "Make easy notes".
3. Listen with "Read all aloud", revise with "Flash cards".
4. Practise with "Make practice questions". Tap "New questions" for a fresh set.

UPDATING THE APP
After changing index.html, open sw.js and change 'exam-buddy-v1' to
'exam-buddy-v2' so phones download the new version.

Note: Do not open index.html by double-clicking to share it. Always share the website link.
